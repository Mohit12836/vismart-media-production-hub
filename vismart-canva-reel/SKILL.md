## 📋 The 4-Phase Production Pipeline

### Phase 1: Research, Hook Scoring & Script Architecture
- **Hook Scoring Rubric:** Every reel must score ≥ 85/100 on the 3-second retention test before rendering.
- **26 Hook Formulas (Selected Favorites):**
  - *Formula 4 (The Contrarian Warning):* "Don't build a [X] in 2026 until you know this..."
  - *Formula 9 (The Money Leak):* "How [Niche Business] lost ₹2.5 Lakhs by ignoring 1 button."
  - *Formula 14 (The Direct Showdown):* "₹5,000 Cheap Template vs ₹50,000 Apple-Grade System."
  - *Formula 21 (The Case Study):* "How Dr. Sharma booked 54 high-paying patients in 14 days without ads."

### Phase 2: Canva Visual Design & SCALE Framework
Every visual asset generated via Canva or imported must adhere to the **SCALE** standard:
- **S - Systemic Brand Kit:** Never use arbitrary colors. Strictly enforce primary brand tokens (e.g. Deep Charcoal `#0F172A`, Pure Alabaster `#F8FAFC`, Electric Blue `#2563EB`, Luxury Emerald `#10B981`).
- **C - Contrast & Safe Zones:** Keep all text and interactive buttons inside the **Instagram Safe Area** (Top Margin: 220px, Bottom Margin: 340px, Side Margins: 60px).
- **A - Anti-Generic Typography:** Strictly no standard generic Canva fonts. Use premium editorial pairings: *Syne + Inter*, *Cabinet Grotesk + Plus Jakarta Sans*, or *Outfit + Noto Sans Devanagari*.
- **L - Layer Separation:** Export foreground elements (stickers, notifications, badges) with transparent backgrounds (`PNG`) so Remotion can apply independent spring animations.
- **E - Elevation & Borders:** Solid 2px dark borders (`border: 2px solid #0F172A`) and sharp drop shadows (`4px 4px 0px #0F172A`).

### Phase 3: Voice Tone, Sound Design & Remotion Motion
- **Voice Tuning (Edge-TTS / Studio TTS):**
  - *Authority Closer:* `hi-IN-MadhurNeural`, Rate: `+8%`, Pitch: `-6Hz` (Deep, commanding male voice).
  - *High-Energy Viral:* `hi-IN-MadhurNeural`, Rate: `+14%`, Pitch: `+2Hz` (Fast, rhythmic pacing).
  - *Calm Healthcare Expert:* `hi-IN-SwaraNeural`, Rate: `+4%`, Pitch: `-2Hz` (Empathetic, reassuring female voice).
- **SFX Synchronization Matrix:**
  - `whoosh.mp3`: On every camera transition / card entrance (Every 1.5s - 2.0s).
  - `pop.mp3`: On sticker, badge, or notification pop.
  - `ding.mp3`: On monetary stat counter or key solution reveal.
  - `bg.mp3`: Low-frequency ducked background beat (Volume: 0.15 during speech, 0.50 during silent beats).

### Phase 4: Quality Assurance & Safe-Zone Export
- Check 1: Zero horizontal overflow on mobile viewports (320px - 480px).
- Check 2: Audio normalization (Peak: -1.0 dBFS, Integrated: -14 LUFS standard for Instagram).
- Check 3: Headless MP4 rendered at 1080x1920 (H.264, CRF 20, 30 FPS).
- Check 4: Dedicated Cover Thumbnail rendered at frame 40 or 60.

## 🛠️ Canva MCP Integration Commands

When Antigravity or the autonomous agent needs to generate Canva visual assets for Remotion:

1. **Brand Kit Discovery:** Fetch colors, typography tokens, and logos using Canva MCP:
   ```json
   {
     "tool": "canva_get_brand_kit",
     "arguments": { "brand_id": "vismart_healthcare" }
   }
   ```
2. **Template Creation:** Initialize a 1080x1920 vertical canvas with safe-zone guides:
   ```json
   {
     "tool": "canva_create_design",
     "arguments": {
       "width": 1080,
       "height": 1920,
       "design_type": "instagram_reel_asset"
     }
   }
   ```
3. **Asset Export for Remotion:** Export transparent foreground PNGs and background cards directly to `production_hub/assets/canva/` for direct Remotion composition referencing.
