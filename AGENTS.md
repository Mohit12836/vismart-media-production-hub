# Media production workflow

For creative planning read `.agents/skills/virality/SKILL.md` and `.agents/skills/storytelling-hooks/SKILL.md`, including its `patterns.md`. For directed motion read `.agents/skills/remotion-motion-graphics/SKILL.md` and its two reference files. Use `.agents/skills/reelcn/archetypes/` for scene-order options. Source commits and MIT notices are in `production_hub/creative_skills.json` and the skill directories.

Translate the guidance into the actual audience and brief; source authors' view counts and rigid timing rules are not universal evidence. Never invent proof, testimonials, commercial results, or retention numbers. A CTA promising a DM/resource needs a real deliverable and explicit authorization for sending messages.

Every directed plan specifies first-frame visual, spoken hook, overlay, payoff, and one visual per spoken scene. Use actual speech timing, not guessed word offsets. Review frames at 0, 0.5, 1.5, 3 seconds and every scene before shipping the MP4. Existing render/delivery approval gates remain in force.

Use retention-audit only with real performance graphs/data. Use channel-formula only with sufficient same-channel winners and failures; store private channel strategy in runtime storage, not source control.
