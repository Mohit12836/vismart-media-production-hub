# Teaching patterns used in the reference reel

- **Analogy first**: Domain = pata (address), Hosting = kamra (room). Show two cards, reveal definitions one by one.
- **Myth busting**: "Google par likha FREE domain*" -> magnifier on the star (*) -> "free nahi, COMBO hai" (burger + fries).
- **Numbered methods**: tareeka 1 / 2 / 3 with lock icons; last one labelled "sabse tagda!".
- **Rename the scary thing**: "Pata me makan-malik ka naam" (vercel.app) -> explain subdomain with a PG building.
- **Proof visual**: show real UI (GitHub PR, is-a.dev JSON, student pack ID card) - recreate as simplified cards, don't paste screenshots of third-party sites.
- **Honest limits**: "Bas 2 baatein" - free plan personal only, domain 1 saal then renewal. Builds trust.
- **Recap flow**: Code -> GitHub -> Vercel -> .me domain -> LIVE (arrow diagram).
- **Engagement CTA**: question for comments ("Pehli website kis cheez ki?"), "ye video us dost ko bhejo", "save kar lo".
- Verify every factual claim (free tiers, offers, dates) via current docs before putting it on screen; add small source footnote.
